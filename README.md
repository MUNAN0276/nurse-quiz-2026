# 2026年在职护士年度考核练习题库

手机网页题库，含1298道题和Word原图。支持顺序练习、随机练习、错题、收藏、进度保存、学习记录导入导出。

## 使用

GitHub Pages使用main分支根目录发布。记录保存在当前浏览器，清理缓存或更换设备前请导出备份。

## 更新题库

修改bank.js中的题干、选项、case、answer，保持id稳定。题目内容或答案改变时同时修改revision（例如2026-10-14-1），旧答题记录就不会计入当前正确率。新增图片放入images目录，使用[[IMAGE:文件名]]引用。病例文字保存在每道相关题目的case中。

答案来自原始复习题库，尚未完成医学专业复核；有疑问请向题库维护者或护理老师反馈。
